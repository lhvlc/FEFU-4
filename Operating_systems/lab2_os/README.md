# Лабораторная работа №2: Кроссплатформенная библиотека запуска процессов

Библиотека на C++ для запуска программ в фоновом режиме с поддержкой:
- Запуска дочерних процессов
- Ожидания завершения с таймаутом
- Получения кода возврата
- Проверки статуса выполнения (isRunning())

Полностью кроссплатформенная: работает на Windows (WinAPI) и POSIX (Linux/macOS).
