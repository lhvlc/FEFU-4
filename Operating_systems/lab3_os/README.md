# Лабораторная работа №3: Кроссплатформенный счётчик с процессами

Программа на C++ без сторонних библиотек, которая:
- Открывает лог-файл и записывает свой PID и время запуска
- Каждые 300 мс увеличивает счётчик на 1 (все процессы)
- Принимает команды пользователя для установки значения счётчика
- Каждую секунду записывает в лог: время, PID, значение счётчика (только ведущий процесс)
- Каждые 3 секунды запускает 2 копии:
  - Копия 1: +10 к счётчику => завершается
  - Копия 2: ×2 => ждёт 2 сек => ÷2 => завершается
- При запуске нескольких экземпляров только первый становится "ведущим" (пишет в лог и запускает копии)

## Кроссплатформенность

| Функция | Windows | Linux |
|---------|---------|-------|
| Разделяемая память | CreateFileMapping + MapViewOfFile | shm_open + mmap |
| Запуск процесса | CreateProcessA | fork + exec |
| Время с миллисекундами | GetLocalTime | gettimeofday |
| Сон | Sleep | usleep |

Весь код автоматически выбирает нужную реализацию через #ifdef _WIN32.
